# Gridiron Commander

An 8-team football GM game you can play in the browser, with no install or build step. Open `index.html`.

- Design your own schedule (each opponent 1–4 times, or a custom number of games) and playoff format
- Play any game live: control any player, drag to aim passes, juke/spin/stiff-arm/truck/dive, tackle, kick with a power/accuracy meter
- Hover a play card (or tap once on a tablet) to preview the formation and assignments
- Ratings blend attributes (70%) with production graded from real stats (30%)
- Fatigue, injuries, penalties, timeouts, the two-minute warning, overtime
- Trades with need-aware AI, "what would it take?" suggestions, shopping players, AI trade offers
- Free agency, re-signing, aging/progression, retirements and rookies across multiple seasons
- Touch controls for tablets: on-screen joystick, context buttons, drag-to-throw

## Controls (keyboard)
`WASD`/arrows move · `Shift` sprint · `Space` snap/juke/dive · `E` spin/jump · `Q` stiff arm · `R` truck · `C` dive · `Tab` switch player · `F` fair catch · `Esc` pause

The league saves to the browser's local storage. You can export and import it from Settings.
